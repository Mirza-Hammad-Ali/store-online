# Forma — Everyday Goods

A small responsive storefront built with React, JavaScript, Tailwind CSS, React Router, and React Icons.

## Run locally

```bash
npm install
npm run dev
```

## Pages

- `/` — home, collections, featured products, and brand story
- `/shop` — product catalog with category filters and add-to-bag buttons
- `/about` — brand story and values
- `/contact` — contact form UI (connect a form service or backend to receive submissions)

Shared UI lives in `src/components`, page components in `src/pages`, and the mapped catalog data in `src/data/products.js`.
